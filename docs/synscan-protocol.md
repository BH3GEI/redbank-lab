# SynScan 协议备忘（实测验证）

自制赤道仪通过 Wi-Fi 热点（SSID `SynScan_ffd1`）暴露 SynScan 协议：

- **传输**：UDP，赤道仪地址 `192.168.4.1:11880`（热点网段 192.168.4.0/24）
- **帧**：`:<命令>\r`，应答以 `=` 开头；出错为 `!<n>`
- TCP 11880/9999 实测**拒绝连接**，只能 UDP

## 实测过的指令

| 指令 | 含义 | 实测应答 |
|---|---|---|
| `:e1` | inquiry（握手/状态） | `=0336C5` |
| `:j1` / `:j2` | 读轴 1(RA)/轴 2(DEC) 编码器 | `=xxxxxx`（6 位 hex，24 位有符号） |
| `:f1` / `:f2` | 轴状态 | `=100` 等 |
| `:K{n}` | 停轴 n | `=` |
| `:G{n}3{d}` | 设轴 n 方向，`d`: 0=CW, 1=CCW | `=` |
| `:I{n}{spd}` | 设轴 n 速度分频（**≤6 位数字**） | `=`；7 位以上报 `!1` |
| `:J{n}` | 启动轴 n | `=` |

> **坑**：`I` 的速度字段最长 6 位十进制。例：轴 1 速度 200000 → `:I1200000`
> （`:I` + `1` + `200000`，注意与读作"速度 1200000"区分，后者会报错）。

## 编码器

- 每转 2^24 = 16777216 计数，即 **46603.4 计数/度**
- 读取值为 **24 位有符号**，等效 ±180° **环绕**（跨接缝会从 +180° 跳到 -180°），
  程序里做相对位移时务必 `wrap180(pos - origin)`

## 让轴转起来的完整序列（实测两轴联动成功）

```
:K1          # 停（保险）
:G130        # 轴1, 方向 CW
:I1200000    # 轴1, 速度分频 200000
:J1          # 启动
...轮询 :j1 直到越过目标...
:K1          # 停
```

分频 200000 时约 5–10°/s（视负载）。数字越小越快。

## 注意事项

1. **进程被杀时电机不停**：SynScan 收到 `:J` 后会一直转，直到 `:K` 或掉电。
   常驻程序必须自带 watchdog（超时自动 `:K`），停止程序前先发 `:K1`/`:K2`。
2. **DEC 有限位**：镜筒不可指向地平线以下。自动化必须先记录上下限再做相对运动。
3. **RA 不宜连续单向 360°**：底座-本体排线会绞。
